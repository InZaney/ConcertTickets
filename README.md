# Concert Tickets
This form will let you fill out what type of concert ticket you want (including price), the amount of tickets you want and will automatically
calculate how much your total cost is.  
NOTE: these prices will not be accurate or based on a specific concert

## Requirements
- .Net 10
- Windows 10/11
- (Prefered) Visual Studio
